# Campus Helpdesk Project

This workspace contains the **Campus Helpdesk** website built with React and Vite.

## Quick Start

Navigate to `campus-helpdesk`:

```bash
cd campus-helpdesk
npm run dev
```

To build for production:
```bash
cd campus-helpdesk
npm run build
```

See [campus-helpdesk/README.md](./campus-helpdesk/README.md) for full documentation, features, architecture, and guides.
